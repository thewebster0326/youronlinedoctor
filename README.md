# Your Online Doctor — youronlinedoctor.co.za

Website for **Your Online Doctor** (Your Online Doctor 0922 (Pty) Ltd), a South
African digital healthcare platform.

Static HTML and CSS generated by a dependency-free Python build script. No
framework, no npm, nothing to install on the server.

## Build

```bash
python build.py
```

That renders every page into the repository root, plus `sitemap.xml` and
`robots.txt`. Python 3.6+ is the only requirement.

## Preview locally

```bash
python -m http.server 4177 --directory .
```

Then open http://localhost:4177

## Layout

```
build.py                 renders every page, sitemap.xml, robots.txt
builder/config.py        brand, contact, services, network, stats, tracking
builder/layout.py        page shell - head, header, footer, GTM, JSON-LD
builder/components.py    reusable section builders
builder/pages.py         page definitions
builder/icons.py         inline SVG icons
static/css/site.css      design system
static/js/site.js        nav, scroll reveals, dataLayer events, consent
static/js/network.js     Three.js hero network scene
assets/                  logo and favicon
*.html                   generated - do not edit by hand, edit builder/ and rebuild
```

**The `.html` files in the root are build output.** Editing them directly gets
overwritten on the next build. Change `builder/` and run `python build.py`.

## Editing content

Almost everything the client changes lives in `builder/config.py`: phone number,
email, address, service lists, network disciplines, the stats figures, and the
navigation. Page copy lives in `builder/pages.py`.

## Tracking

Google Tag Manager is scaffolded but **off**. To switch it on, set a real
container ID and `enabled = True` in `TRACKING` in `builder/config.py`, then
rebuild. Everything downstream — GA4, Google Ads conversions, Meta Pixel — is
configured inside GTM, not in this codebase.

`dataLayer` events already fire on `whatsapp_click`, `call_click`,
`email_click` and `consent_choice`, each carrying `link_location` so you can
tell a header click from a hero click from a footer click.
